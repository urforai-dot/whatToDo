## 메모

**T004(Supabase) 연결 전까지는 이 task를 완전히 끝낼 수 없다.** Supabase가 연결되면 다음 순서로 마무리해야 함:
1. `npm run db:migrate` (drizzle/0000~0003 적용)
2. `npm run db:seed` (12개 샘플 업무)
3. 로그인 → 우선순위/워크로드 확인 → 업무 추가(add-task-bar) → 담당자 배정(상세 패널 칩) → 코멘트 작성 → 상태를 done으로 변경 → `/history`에서 확인, 순서로 실제 클릭 테스트
4. 문제 있으면 각 task를 `needs_review`로 되돌리고 고친 뒤 다시 `done`
