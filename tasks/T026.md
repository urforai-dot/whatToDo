# T026 — 완료 보고서 작성/편집 UI

- **단계(phase)**: 완료 업무 & 보고서 (report-ui)
- **상태**: done
- **예상 소요**: 30분
- **선행 작업(dependencies)**:
- T012
- T025

## 설명

담당자가 업무를 완료 처리할 때 요약 보고서를 작성/수정할 수 있는 UI를 구현한다.

## 목표

완료 시점에 보고서를 남기도록 유도해 공유 가능한 기록을 만든다.

## 관련 요구사항 (개발요구사항문서.md)

> STEP 1 - 완료된 업무의 보고서를 보고 어떤 식으로 진행되었는지 알 수 있다

## 완료 조건 (Acceptance Criteria)

- [x] 코멘트 입력창은 상태와 무관하게 상세 패널에 항상 노출됨 — "완료로 바꿀 때만" 뜨는 별도 보고서 폼 대신, 진행 중에도 코멘트를 계속 남기고 완료 시점 코멘트도 같은 흐름으로 남기는 방식 (T006 메모: report 필드 대신 comments)
- [x] 작성한 코멘트가 POST /api/tasks/:id/comments로 저장됨 (세션 사용자로 작성자 자동 지정)

## 메모

"완료로 바꿀 때만 보고서 입력창이 뜬다"는 원래 AC는 구현하지 않았다 — comments 기반으로 설계를 바꾸면서, 완료 시점에만 쓰게 강제하는 것보다 진행 중에도 자유롭게 기록을 남기는 쪽이 실제 요구사항("완료된 업무가 어떻게 진행됐는지 알 수 있다")에 더 맞다고 판단했다.
