# T026 — 완료 보고서 작성/편집 UI

- **단계(phase)**: 완료 업무 & 보고서 (report-ui)
- **상태**: todo
- **예상 소요**: 30분
- **선행 작업(dependencies)**:
- T012
- T025

## 설명

담당자가 업무를 완료 처리할 때 요약 보고서를 작성/수정할 수 있는 UI를 구현한다.

## 목표

완료 시점에 보고서를 남기도록 유도해 공유 가능한 기록을 만든다.

## 관련 요구사항 (개발요구사항문서.md)

> STEP 1 - 완료된 업무의 보고서를 보고 어떤 식으로 진행되었는지 알 수 있다

## 완료 조건 (Acceptance Criteria)

- [ ] 업무를 완료 상태로 변경할 때 보고서 입력 UI가 노출됨
- [ ] 작성한 보고서가 PATCH API를 통해 저장됨
