# T023 — 업무 상태/우선순위 변경 UI

- **단계(phase)**: 업무 추가/변경 UI (task-crud-ui)
- **상태**: todo
- **예상 소요**: 30분
- **선행 작업(dependencies)**:
- T012
- T017

## 설명

보드/리스트에서 업무 상태나 우선순위를 바로 변경할 수 있는 UI(드롭다운 또는 드래그)를 구현한다.

## 목표

우선순위 조정을 빠르게 할 수 있게 하여 조율 시간을 단축한다.

## 관련 요구사항 (개발요구사항문서.md)

> STEP 1 - 다음 업무 및 우선순위 조정을 쉽게 할 수 있음

## 완료 조건 (Acceptance Criteria)

- [x] 업무 상세 패널(행 클릭 시 열림)에서 상태/우선순위 드롭다운을 바꾸면 PATCH API가 호출됨 (목록에서 바로 드래그하는 방식은 2a 디자인에 없어서 상세 패널 방식으로 구현 — 메모 참고)
- [x] 변경 결과가 화면에 즉시 반영됨 (patchTask 후 재조회 + 목록 위젯도 reload)
- [x] (보너스) 담당자 배정도 같은 패널에서 이름 칩 토글로 가능

## 메모

목록 행에서 바로 드래그/인라인 편집하는 UI는 만들지 않았다 — 승인된 2a 디자인의 목록 행은 읽기 전용이고 "행 클릭 → 코멘트/상세"가 정해진 인터랙션이라, 그 상세 패널 안에 상태/우선순위/담당자 편집을 넣는 쪽이 디자인과 일관된다.
