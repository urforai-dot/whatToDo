# T013 — 업무 상세/보고서 조회 API

- **단계(phase)**: 백엔드 API (backend-api)
- **상태**: todo
- **예상 소요**: 30분
- **선행 작업(dependencies)**:
- T010

## 설명

GET /api/tasks/:id 구현: 업무 상세 정보와 완료 보고서를 함께 반환한다.

## 목표

완료 업무의 상세 내용을 누구나 조회할 수 있게 한다.

## 관련 요구사항 (개발요구사항문서.md)

> STEP 1 - 완료된 업무의 보고서를 보고 진행 방식을 알 수 있다

## 완료 조건 (Acceptance Criteria)

- [x] GET /api/tasks/:id가 업무 상세 필드와 담당자 목록, 코멘트/활동 이력(comments, 최신순)을 반환함 — "report"는 T006 메모에 적은 대로 comments 이력으로 구현

## 메모

report 필드가 아니라 comments 테이블을 최신순으로 붙여 반환한다 (T006 메모 참고). authorId는 요청 바디가 아니라 세션 쿠키에서 가져오게 되어 있으니(POST /api/tasks/:id/comments) 다른 사람 이름으로 코멘트를 다는 게 불가능하다.
