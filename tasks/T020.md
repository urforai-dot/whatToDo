# T020 — 필터(담당자/상태/기간) UI

- **단계(phase)**: 대시보드 UI (dashboard-ui)
- **상태**: cancelled
- **예상 소요**: 30분
- **선행 작업(dependencies)**:
- T017

## 설명

대시보드에서 담당자, 상태, 기간으로 업무를 필터링하는 UI를 구현한다.

## 목표

원하는 조건으로 업무를 빠르게 좁혀볼 수 있게 한다.

## 관련 요구사항 (개발요구사항문서.md)

> STEP 4 - 핵심 시나리오 2

## 완료 조건 (Acceptance Criteria)

- [ ] ~~담당자/상태/기간 필터를 조합해 목록이 갱신됨~~ (취소 — 메모 참고)
- [ ] ~~필터 초기화가 가능함~~ (취소)

## 메모

**취소함**: 사용자가 승인한 Claude Design "2a 위젯보드" 안에는 필터 바가 없다 (이건 1a 표 레이아웃의 기능이었는데, 최종 선택된 건 2a). 2a는 필터 대신 "담당자별 현황" 위젯(owner 전원을 항상 보여줌), "확인 필요" 위젯(홀드/미배정/일정미정 자동 분류), "행 클릭→코멘트"로 원하는 정보에 접근하는 방식이라 결이 다르다. 억지로 필터 바를 끼워넣으면 승인된 디자인을 깨게 돼서, 이 task는 취소하고 backend API의 필터 쿼리 파라미터(status/owner/priority, T010에 구현됨)는 남겨뒀다 — 나중에 필요해지면 UI만 얹으면 된다.
