# T012 — 업무 수정 API (상태/우선순위 포함)

- **단계(phase)**: 백엔드 API (backend-api)
- **상태**: waiting
- **예상 소요**: 30분
- **선행 작업(dependencies)**:
- T010

## 설명

PATCH /api/tasks/:id 구현: 상태 변경, 우선순위 변경, 담당자 변경을 포함한다.

## 목표

업무 상태/우선순위 조정을 백엔드에서 지원한다.

## 관련 요구사항 (개발요구사항문서.md)

> STEP 1 - 우선순위 조정을 쉽게 할 수 있음

## 완료 조건 (Acceptance Criteria)

- [x] PATCH /api/tasks/:id로 title, description, model, status, priority, startDate, dueDate, ownerIds 부분 업데이트가 가능함 ("report" 필드는 없음 — T006 메모 참고, comments로 대체)
- [x] 존재하지 않는 id에 대해 404를 반환함
- [x] 업무 수정 + 담당자(ownerIds) 교체는 하나의 DB 트랜잭션으로 처리됨 (adversarial-reviewer 지적: 트랜잭션 없이 하면 담당자 교체 중 실패 시 업무에 담당자가 0명으로 남는 데이터 유실 가능)

## 메모

존재하지 않는 ownerIds를 보내면(예: 탈퇴한 사용자) 트랜잭션 시작 전에 검증해서 400을 반환한다.
