## 메모

GitHub 저장소 자동 연동(push하면 자동 배포)은 안 돼 있음 — `vercel link` 때 "Connecting GitHub repository" 단계가 실패했었다(Vercel 쪽 GitHub App 설치 필요해 보임). 지금은 `vercel deploy`/`vercel deploy --prod`를 수동으로 실행해야 배포된다. 자동배포를 원하면 Vercel 대시보드에서 GitHub App 연결을 사람이 한 번 해줘야 할 수 있음.
